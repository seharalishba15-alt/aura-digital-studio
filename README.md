# AURA | Digital Studio

A professional digital studio website built with HTML, CSS and JavaScript.

## Features

* Responsive design
* Dark/light mode
* Interactive service and project modals
* Contact form with Formspree
* Scroll animations
* Animated statistics
* Back-to-top button
* WhatsApp contact button

## Technologies

* HTML5
* CSS3
* JavaScript
* Formspree

## Project

AURA Digital Studio is a modern agency-style website designed to showcase web development, UI/UX design, and brand identity services.
